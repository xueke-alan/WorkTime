# 动画兼容性加固

## 行为

- 继续跟随 `prefers-reduced-motion`，不新增开关，不改变存档或备份格式。
- 侧栏切换、批量抖动、年月标题切换使用传统 `transform`；标题变换保留文字对齐偏移，SVG 分隔符不应用文字偏移。
- `animation-compat.js` 在动画消费者之前加载，提供内部 `preference`、`listen`、`animate`、`decode` 接口。媒体查询监听兼容新旧事件 API。
- 一次性 Web Animations 动画返回可取消的句柄及始终正常结算的 `finished` Promise；缺少 `animate` 或调用失败时直接完成，缺少原生完成 Promise 时使用动画时长加 100ms 的兜底。完成和取消均释放原生动画及填充效果。
- 数字滚动使用 CSS 暂停/恢复、结束/取消事件以及可取消的收尾计时器，不依赖 `getAnimations`；隐藏页面、减少动态效果和组件销毁都会显示最终数值。
- 天气切换保留先淡出后淡入的顺序；图片解码缺失或失败时继续，解码无响应时最多等待 1000ms。解码等待和动画均可取消，旧回调不能更改新图标；销毁也会清理已移出 DOM 的图标任务。
- 通知动画和长按回退不再直接依赖可选动画 API，旧回退完成不能清除新一轮长按状态。

## 验证（2026-10-08）

真实浏览器：Windows 上的无界面 Microsoft Edge 154.0.4258.62，通过项目 Playwright 测试运行。

`node tests/animation-compat.browser.cjs` 覆盖九种场景：正常、缺少 `getAnimations`、缺少 `animate`、缺少原生完成 Promise、动画调用抛错、仅旧式媒体查询监听、动画兼容模块遇到缺少媒体查询 API、图片解码拒绝、图片解码一直不返回。缺少媒体查询的场景只验证兼容模块自身，并非声明整个应用支持没有 `matchMedia` 的浏览器。

上述场景验证数字连续变化和最终显示、动画结束事件丢失、隐藏页面与运行中切换系统偏好、连续天气更新、短按复位、重复批量选择和设置页面切换、卡片变换；正常及关键降级场景额外验证长按重启、取消和恰好一次完成。

相关回归全部通过：

- 动画和通知生命周期、数字预览、天气图标切换。
- 年视图、控件（11 个宽度 × 4 DPR）、我的设置、离线启动、启动失败及六种启动退出阶段、脚本命名空间与顺序。
- 154 个日历样式状态、66 个页面样式状态、88 个汇总样式状态。
- 原 CSS 与新 CSS 在 390/1600/2250px 下的月视图、年视图和返回月视图几何对比一致；结果与截图保存在 `test-results/animation-compat-layout.json`、`test-results/animation-compat-layout-1600.png`。
- 项目语法检查（222 项）、完整 lint 和源码格式检查；最终编辑的源码与测试另作 lint/格式复查。

日历测试保留冻结基线：年标题先校验合并后的横向位移数值，再比较剩余变换与完整几何位置，不直接忽略 `transform` 差异。

## 验证边界

能力缺失通过在真实浏览器中模拟验证，不等同于已经测试旧版浏览器或其他浏览器内核。没有引入转译、大型 polyfill 或 IE 支持。系统偏好关闭动画时，效果仍按原设计关闭。
