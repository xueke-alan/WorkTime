# CSS 组件与验证契约

## 所有权与加载顺序

`tokens.css` 先于全部组件加载，集中主题色、尺度、尺寸、字体家族和动画变量。`base.css` 负责重置、共享表面、字段默认值和通用工具类；`layout.css` 负责工作区及页面响应式布局。`editor.css`、`dialogs.css`、`date-info.css`、`weather.css`、`summary.css`、`calendar.css` 各自拥有组件结构与断点。`controls.css` 提供普通按钮及时间/数值输入外观，`icons.css` 提供图标规则，`motion.css` 提供动画与关键帧。

普通动作显式声明 `ui-button`，文字层由 HTML 或创建按钮的组件声明 `button-label`。图标按钮声明 `icon-only`；页签、日期导航、城市选项和月/年日期由各自组件管理。对齐服务不能给任意按钮添加类型或包装文本。

六种主题共享语义角色，调色板只提供各自颜色；新增主题需要核对文字、边框、焦点、图标及通知的可读性。布局尺寸不随主题变化。

## 字体和测量

普通按钮只根据实际字号选择公共字体档，不按文字内容测量偏移。日期、统计、标题及黄历等显式特殊文字层保留 TextMetrics、基线探针和日期像素边界测量；数字动画轨道不参与单行文字测量。计算样式的百分比 `fontStretch` 转换为 Canvas 接受的关键词。

TextMetrics 缓存上限为 512，日期栅格缓存上限为 128；字体事件使缓存失效。探针按批写入、连续读取并集中移除，最后写回校正。隐藏、空文本及多行标签不应用单行校正。普通保存与倒计时刷新限定在组件作用域；字体、根布局和容器替换允许完整刷新。

组件观察器在隐藏页面时暂停，`dispose` 取消调度并断开观察。不能用文本测量补偿其他组件的结构缺陷。

## 交互与层叠

键盘焦点使用控件内部细线，保留点击区域和布局；不增加外圈。主按钮的提示须保持颜色对比，鼠标状态不变。月历按日历容器宽度排版，短窗口可在月历内部滚动；编辑器时间字段与次日开关保持输入高度。

`!important` 仅用于隐藏状态、固定控件几何/字体的明确例外、复合控件、减少动态效果及必要的内部焦点提示。修改时检查实际获胜声明，不能仅按数量删除。

动画能力缺失、页面隐藏或系统减少动态效果时仍须到达最终可用状态。天气退场/入场、数字滚动、长按反馈均须可取消；详见 `ANIMATION_COMPATIBILITY.md`。

## 维护工具

`scripts/clean-css.cjs` 默认只删除同选择器、同条件、同属性/值/优先级的重复声明和空规则，再格式化；保留建立层叠顺序的空 layer。`pruneShadowed` 仅处理同选择器/条件/优先级且确认支持的后置覆盖；`consolidateAdjacent` 只合并相邻且同条件的块，不跨注释、层、关键帧或中间规则重排。跨选择器删除需独立核对层叠和使用路径。

## 验证

`npm run test:styles` 比较五类固定参考：整页 66、资讯 88、汇总 88、日历 154、编辑器/弹窗 352，共 748 个状态。参考文件及来源信息保存在 `tests/fixtures/`，属于必要测试输入。新增预期视觉变化需有明确依据，不能覆盖旧参考来掩盖差异；捕获新参考使用唯一标签。

`button-ink.browser.cjs` 检查 3 类按钮 × 24 宽度 × 4 DPR 的文字中心、共同基线、图标和命中区。主题、键盘焦点、日历响应式、布局局部更新和生命周期另有专项检查。样式基线来自 Windows Edge 和项目字体环境；计算样式与几何比较不等于完整像素对比，也不代表验证了所有系统缩放或浏览器内核。

测试差异、截图和报告统一写入 `test-results/`。历史阶段报告只在本地或 Git 历史保留，不属于当前源码的验收证明。

当前默认参考为 tests/fixtures/styles-*-2026-10-08.json.gz，旁附来源哈希及逐组件接受变化；2026-10-04 参考保留不变。新增参考记录目标区布局、节日与来源标记、倒计时按钮、设置返回文案及 OA 核心文本说明，比较仍为逐属性、逐几何精确相等。
