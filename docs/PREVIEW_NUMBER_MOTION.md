# 右侧预览数字滚动动画

用户在重构交付后追加要求：右侧预览的数字也使用新版滚动动画。本次已将应出勤工时/天数、已出勤工时/天数、平均加班和入职天数接入现有SummaryNumbers组件。数值增加/减少沿相应方向滚动，相同值不重复触发，单位保留，`- h`仍为不可计算占位。初次揭示覆盖右侧数字，系统减少动画时直接显示最终值。

预览区span样式收窄为列的直接子节点，避免污染新增数字条字体和行高；未改工时计算、存储或日历规则。相同预览markup保留节点，原保存失败重试及幂等更新检查通过。

[定点结果](preview-number-motion-results.json)：390/1600宽度×正常/减少动画共4个真实页面场景通过；覆盖初次揭示、增减方向、相同值保留节点、单位/字体/入职日期变化/不可计算占位。另完成保存回归及启动故障保护/6生命周期检查，修改JS/test的lint和格式检查通过。已查看正常动画结束后的桌面和小屏截图。

此版本追加动画改变预览DOM及动画等待工作量；[此前完整性能报告](PERFORMANCE_FINAL.md)及stage32快照保留为追加需求之前的历史版本，不冒称测量已覆盖本改动。按照用户减少重复门禁要求，本次仅定点验证，没有重复完整748样式矩阵或60次性能采集。当前增量回退快照与SHA256见实施记录。
