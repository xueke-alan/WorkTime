## 完整对局

每组 2,000 局，四席各 500 局，使用新的未训练评测种子 9100000–9101999。每局一名受测玩家对三名相应对手，各自争胜。共 8,000 局均正常结束；未排除超时或未完成对局。普通档结果同时用于配对比较，未重复计为独立实验。

| 受测玩家 | 三名对手 | 获胜局数 | 胜率 | Wilson 95% 置信区间 |
| --- | --- | ---: | ---: | ---: |
| 普通模型 | 随机合法行动 | 1,411 | 70.55% | 68.51%–72.51% |
| 普通模型 | 固定策略 | 614 | 30.70% | 28.72%–32.76% |
| 困难模型 | 固定策略 | 681 | 34.05% | 32.01%–36.16% |
| 关闭模型、保留普通档搜索 | 固定策略 | 153 | 7.65% | 6.56%–8.90% |

普通档对固定策略的胜率置信区间下界为 28.72%，超过四人均势基准 25%。相同种子和席位的配对比较：困难档比普通档提升 3.35 个百分点，配对 95% 置信区间 0.85–5.85 个百分点；普通模型比关闭模型提升 23.05 个百分点，配对 95% 置信区间 20.87–25.23 个百分点。三项发布门槛均通过。

固定策略按到家、撞机、起飞与推进排序，仅用于训练和评测。关闭模型对照将两个头置零，保留相同普通档搜索预算和采样。评测关闭时间截止、保留节点上限；网页运行仍有时间上限。未测量真人胜率或与其他产品的强弱关系。

## 复验与兼容

`npm run aeroplane:evaluate` 复验冻结候选，全部门槛通过后使用 `npm run aeroplane:export` 发布权重。重新训练的新候选必须通过相同验收。

`node scripts/verify-aeroplane.cjs` 验证六格与完整入口几何、终点反弹、规则 1 存档迁移、真实模型与 Worker 一致性、动画路径、四方基地骰子、六个顶面点数、120 次真实随机掷骰、六语言及源码／发布版离线运行。日志与截图位于 `test-results/aeroplane/`。

历史预览规则报告保留在 [规则 1 报告](EVALUATION-v1.md)，其中的七格终点与旧胜率不适用于当前规则。
