# 飞行棋：本地模型、训练与验收

网页游戏入口为「飞行棋」。四个席位可分别设为真人或电脑，至少一位真人；红方先行。支持简单、普通、困难、同屏多人、暂停、自动续局和游戏存档导入导出。模型随项目分发，直接打开 `index.html` 即可游玩。

## 棋盘与规则

棋盘采用连续直角航道、三角转角、约占边长五分之一的基地和中央四色三角终点。四角顺序为左上黄、右上蓝、右下绿、左下红。飞机到家后分别停在本色终点内。触屏除直接点机外，也可使用侧栏的大号选机按钮。

棋盘优先使用可用空间，不显示额外标题、底部说明或基地计数。各方在自己的基地内掷六面立方体骰子，经过旋转、落地反弹与阴影变化后，顶面显示实际骰点。尚未掷过的骰子显示空白面。普通移动逐格缓入缓出，同色跳跃沿途经过每个航道格，跨盘飞跃沿虚线通过中点；不显示落点提示圈、飞行线中点圆圈或终点入口箭头。棋子保留有边框和厚度的圆形底座，使用简洁的单色飞机图案，撞机后平滑返回机库。减少动态效果时直接呈现结果。

六点起飞至独立起飞位，下次掷骰从紧邻起飞位的第一格开始计步；起飞位的内部标记不参与步数相加。每次六点均奖励再掷。外圈相对步数为 1–50，终点通道为 51–55 共五格，56 为中央终点，向内共六格（含终点）。直接落在本色格跳四格，直接到达相对第 18 格则优先飞至 30，不递归执行奖励。飞跃中点为对面玩家的终点通道第 53 格；此格与最终落点的全部敌机回库，普通经过不撞机。叠机独立移动、不设阻挡。终点超出则反弹，四架到家立即获胜。

规则版本为 2；预览版规则 1 的存档会合并重复入口格，已完成的飞机与终局仍保持完成。早期预览误存为第 0 格的飞机会自动纠正到第 1 格，其余进度保留。

规则、几何坐标、转角多边形、合法动作和存档校验集中在 `assets/js/games/aeroplane-rules.js`。训练、浏览器、Worker 直接使用这份实现。存档保留最近 64 次已掷骰结果；模型不接收未来骰子或实际随机数发生器状态。

## 模型与难度

模型由线性策略打分头与 tanh 动作价值头组成，共 28 个训练参数。14 项公开局面特征包括推进、起飞、到家、撞机收益、按六面骰枚举的受撞概率及同格风险。浏览器直接计算前向结果，无需额外推理框架。

先用短搜索生成动作价值目标并进行梯度拟合，再以历史模型与固定策略混合对手进行 12 代进化式自博弈优化，最后用 600 局终局回报拟合价值头。检查点和样本留在 `.cache/aeroplane-training/`，不自动覆盖网页权重。

简单档使用模型打分及温度 4 的采样；普通档温度 0.7，至多 2 轮随机前瞻；困难档确定性择优，至多 16 轮。每个候选、每轮模拟 12 次掷骰，普通／困难最多 96／768 个模拟步。各档还受约 0.1／0.5／1.5 秒上限约束，通常会先达到节点上限。只有模型计算在 Worker 内运行；真人和电脑的实际掷骰由游戏控制器生成。

模型通过 SHA-256 校验后使用。加载、校验、Worker 或计算失败会停止对局并允许重试。暂停、退出、重开与页面进入后台会终止 Worker、取消动画并忽略过期结果。

## 命令

使用项目要求的 Node.js 版本，无需 Python、GPU 或在线模型接口。

```powershell
npm run aeroplane:train
npm run aeroplane:resume
npm run aeroplane:evaluate
npm run aeroplane:export
npm run aeroplane:test
```

`train` 创建新候选；`resume` 从最近候选继续未完成的训练阶段，完整检查点再次续训不会改写权重。`evaluate` 使用冻结候选和未参与训练的种子 9300000–9301999，四席各 500 局。评测关闭时间截止、保留节点上限，避免机器速度影响比较。普通档对随机、固定策略各测 2000 局；困难档和关闭两个模型头的同预算搜索对照各测 2000 局。训练使用其他固定种子和自博弈对局编号。

普通档胜率的 Wilson 95% 置信区间下界必须超过 25%；困难档相对普通档、模型相对关闭模型的配对胜率差，其 95% 置信区间下界均须大于零。普通档的固定策略结果同时作为配对比较的普通档结果，不重复计为另一组独立实验。

只有上述门槛全部通过，且候选权重、规则及推理源码哈希与报告匹配，`export` 才能生成网页资源。发布权重与机器可读报告位于 `assets/vendor/aeroplane/`，最终结果见 [评测报告](EVALUATION.md)。

## 验证

```powershell
node scripts/verify-aeroplane.cjs --unit
node scripts/verify-aeroplane.cjs
node scripts/verify-aeroplane.cjs _site
npm run check
npm run lint
npm run check:format
```

验证包括规则边界、飞跃线与可撞中点重合、随机完整对局、真实模型与 Worker 数值一致性、存档导入导出和合并、四席配置、六语言、主题、桌面和手机布局、动画取消、模型故障重试，以及源码和发布产物的本地文件入口、HTTP 与使用后的断网重载。

规则、推理和训练工具均为本项目独立实现，权重由本工具实际训练，无第三方权重依赖。首次通过在线页面离线游玩前，需要联网打开游戏并完成一次模型计算，以准备浏览器缓存；本地文件入口直接使用随包资源。
