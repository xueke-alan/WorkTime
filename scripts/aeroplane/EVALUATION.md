# 飞行棋模型 2.0.1 回归评测

修复起飞位标记 -1 误参与骰点相加的问题：掷六先到起飞位，后续从紧邻的第 1 格开始计步。绿色首格为基地旁的蓝色三角格；其余颜色按旋转后的相同规则行进。旧存档误存的第 0 格会自动纠正到第 1 格。

## 模型与冻结

沿用 2.0.0 已训练权重，完成起飞计步修复后的独立回归及档位校准。普通档采样温度为 0.7，困难档确定性择优，搜索预算沿用原设置。四席人数、骰子随机性及真人合法走法由统一规则决定。

训练来源：55,524 条搜索样本、12 代进化式自博弈（15,360 局）、600 局终局价值拟合（169,158 条样本）；合计 28 个训练参数。

## 完整对局

每组 2,000 局，四席各 500 局，最终验收使用未参与训练及开发校准的新种子 9300000–9301999。每局一名受测玩家对三名相应对手，各自争胜。共 8,000 局均正常结束，没有排除超时或未完成对局。普通档结果复用于配对比较，未重复计数。

| 受测玩家 | 三名对手 | 获胜局数 | 胜率 | Wilson 95% 置信区间 |
| --- | --- | ---: | ---: | ---: |
| 普通模型 | 随机合法行动 | 1,341 | 67.05% | 64.96%–69.08% |
| 普通模型 | 固定策略 | 691 | 34.55% | 32.50%–36.66% |
| 困难模型 | 固定策略 | 792 | 39.60% | 37.48%–41.76% |
| 关闭模型、保留普通档搜索 | 固定策略 | 178 | 8.90% | 7.73%–10.23% |

普通档对固定策略的置信区间下界 32.50% 超过 25%。同种子、同席位的困难档比普通档提升 5.05 个百分点（配对 95% 置信区间 2.49–7.61）；普通模型比关闭模型提升 25.65 个百分点（配对 95% 置信区间 23.35–27.95）。三项门槛均通过。

固定策略按到家、撞机、起飞与推进排序，仅用于训练和评测。关闭模型对照将两个头置零，保留普通档搜索和采样。评测关闭时间截止并保留节点上限；网页运行仍有时间上限。未测量真人胜率或与其他产品的强弱关系。

## 复验与兼容

`npm run aeroplane:evaluate` 复验冻结候选，全部门槛通过后执行 `npm run aeroplane:export`。重新训练的新候选仍须通过同一门槛。

`node scripts/verify-aeroplane.cjs` 验证四个颜色的出库、起飞、掷一首步及实际渲染坐标，旧存档自动修复，六格终点与反弹，模型与 Worker 一致性，动画、骰子、六语言和源码／发布版离线运行。日志及截图位于 `test-results/aeroplane/`。

历史结果保留在 [2.0.0 报告](EVALUATION-v2.0.0.md) 与 [规则 1 报告](EVALUATION-v1.md)，它们只适用于当时的规则与配置。
