# 飞行棋模型 2.0.1：撞机与快速通道回归评测

修复首次落在同色格时漏撞机，以及跳到快速通道入口后未继续飞跃的问题。首次落点、跳跃落点、飞跃中点与终点的敌机均回库；飞跃后不继续跳跃，普通经过不撞机。四种颜色遵循同一规则。

## 模型与冻结

沿用 2.0.1 网页模型及其已训练权重，完成撞机与快速通道修复后的回归评测。普通档采样温度为 0.7，困难档确定性择优，搜索预算沿用原设置。四席人数、骰子随机性及真人合法走法由统一规则决定。

训练来源：55,524 条搜索样本、12 代进化式自博弈（15,360 局）、600 局终局价值拟合（169,158 条样本）；合计 28 个训练参数。

- 规则、推理源码哈希与档位配置保存在 `assets/vendor/aeroplane/evaluation.json`，导出时再次核对。

## 完整对局

每组 2,000 局，四席各 500 局，本次回归沿用未参与权重训练的固定种子 9300000–9301999。每局一名受测玩家对三名相应对手，各自争胜。共 8,000 局均正常结束，没有排除超时或未完成对局。普通档结果复用于配对比较，未重复计数。

| 受测玩家 | 三名对手 | 获胜局数 | 胜率 | Wilson 95% 置信区间 |
| --- | --- | ---: | ---: | ---: |
| 普通模型 | 随机合法行动 | 1,320 | 66.00% | 63.90%–68.04% |
| 普通模型 | 固定策略 | 673 | 33.65% | 31.61%–35.75% |
| 困难模型 | 固定策略 | 805 | 40.25% | 38.12%–42.42% |
| 关闭模型、保留普通档搜索 | 固定策略 | 171 | 8.55% | 7.40%–9.86% |

普通档对固定策略的置信区间下界 31.61% 超过 25%。同种子、同席位的困难档比普通档提升 6.60 个百分点（配对 95% 置信区间 3.99–9.21）；普通模型比关闭模型提升 25.10 个百分点（配对 95% 置信区间 22.84–27.36）。三项门槛均通过。

固定策略按到家、撞机、起飞与推进排序，仅用于训练和评测。关闭模型对照将两个头置零，保留普通档搜索和采样。评测关闭时间截止并保留节点上限；网页运行仍有时间上限。未测量真人胜率或与其他产品的强弱关系。

## 复验与兼容

`npm run aeroplane:evaluate` 复验冻结候选，全部门槛通过后执行 `npm run aeroplane:export`。重新训练的新候选仍须通过同一门槛。

`node scripts/verify-aeroplane.cjs` 验证四个颜色的出库、起飞、掷一首步及实际渲染坐标，旧存档自动修复，六格终点与反弹，模型与 Worker 一致性，动画、骰子、六语言和源码／发布版离线运行。日志及截图位于 `test-results/aeroplane/`。

起飞计步修复时的结果保留在 [起飞计步报告](EVALUATION-v2.0.1-first-square.md)。更早的历史结果保留在 [2.0.0 报告](EVALUATION-v2.0.0.md) 与 [规则 1 报告](EVALUATION-v1.md)，它们只适用于当时的规则与配置。
