# HWorkTime · 工时记录

用于记录工时、安排日程和查看作息统计的个人工具，支持电脑和手机使用。

[在线使用](https://xueke-alan.github.io/WorkTime/)

## 基本功能

- **熄灯谜题**：沿用数字华容道的布局，点击图案翻转自身与上下左右相邻图案，让所有图案归于沉静。共 100 道原创预设谜题，4×4 至 7×7 各 25 关，分别搭配深海光珠、星夜、晶洞和能量光环美术；全部采用高难度题目，每章按精确最少步数排序，全部关卡开放，支持撤销、重开、最佳成绩、离线续玩及游戏存档导入导出。
- **工时记录**：记录上下班、跨日打卡、请假和计划加班，支持批量填写、时间模板与 OA 考勤导入。
- **日程安排**：管理全天、定时和跨天事项，标记待办、进行中、已完成或已取消，支持月、周、双周和三周视图；周视图提供可拖动、调整时长的时间表，并可只显示工作日。
- **统计分析**：查看工时、加班和月度目标进度，分析上下班时间、加班分布及较上月的变化，通过侧栏联动查看每日详情。
- **自定义作息**：设置工作时间、休息时段和加班要求，也可按日期范围调整。
- **日历信息**：提供年度热力图、下班倒计时、天气、节日、农历和历史事件。
- **备份恢复**：数据保存在当前浏览器，支持备份导出、恢复、历史快照及自动备份。
- **个性设置**：提供多种主题，支持简体中文、繁体中文（台湾／香港）、英语、日语和韩语。
- **本地音乐**：右下角音乐按钮打开播放器，像游戏模式一样从中间栏展开，导入本地音乐后可播放、搜索、收藏，支持循环、随机、倍速、睡眠定时和本地歌词；收起后恢复原视图并继续播放。
- **休闲游戏**：内置 2048、扫雷、贪吃蛇、数独、推箱子、跳一跳、连连看、羊了个羊、坦克大战、象棋残局和五子棋残局。五子棋残局沿用象棋的选关与对弈布局，提供 100 道原创 VCT 连续威胁残局，按初级 40 题、中级 30 题、高级 30 题分类；旧版一步、两步、三步基础题已全部移出菜单。VCT 已验证路线为黑方 4–6 步，结合活三衔接次数与搜索复杂度排序，排除平移、旋转、镜像重复及相同黑方棋形，采用 15×15 无禁手规则，支持自动应手、整轮悔棋、重开、键盘操作、离线续局和游戏存档导入导出。象棋残局有 200 关，包含一步杀 20 题、两步杀 30 题、三步杀 30 题，以及 120 道具名《适情雅趣》经典长杀；基础题连续编号 01–80，经典题按初级（4–5步）、中级（6–8步）、高级（9步以上）分类，支持离线游玩、悔棋和续玩。部分关卡取自 [Xiangqi Arena](https://github.com/dffge552/xiangqi-pwa-offline)，许可见 [题库许可证](licenses/xiangqi-puzzles.txt)。
- **推箱子进阶题库**：共 140 关，采用入门、进阶、熟练、专家、高阶专家、极难、大师七档，各 20 题，分别搭配清新森林、沙漠遗迹、琉璃花房、冰川遗迹、太空基地、黄铜工坊、云端天宫七套浅色美术。原有 100 题的稳定 ID、地图和解法全部保留，展示编号按新分档重排，旧进度按 ID 恢复。来源为 David W. Skinner 的 Microban / Sasquatch，许可见 [题库说明](licenses/sasquatch.txt)。全部解法已回放验证，新题解法不宣称最优；支持离线游玩、续玩和存档导入导出。
  题库重建：`node scripts/import-sokoban.cjs`；一致性检查：追加 `--check`。固定选题、旧题兼容指纹和新顺序在 `scripts/sokoban-selection.json`。统一难度指标为推箱次数 + 3×箱子切换次数 + 12×移出目标次数 + 5×箱子数，按分值与稳定 ID 排序后每 20 题分档。名称与分数区间参考 [Cosmos 作者的七档说明](https://aymericdupeloux.wixsite.com/sokoban/post/welcome)，题目归档为本地估计，不是原作者对这些题目的评级，也未使用其需要另行许可的题库。诊断求解：`node scripts/import-sokoban.cjs --solve sasquatch-5 3`（有预算限制，不改题库、不宣称最优）；求解使用反向推箱距离与箱子／目标最小代价匹配。地图限制在 20×20 格以内，排除原文注明的 SokHard 衍生题。

数独共 490 关：标准数独四档难度各 20 关，杀手数独 30 关，其余 19 类变体各 20 关，包括奇偶、温度计、摩天楼、三明治、杀手、箭头、不规则宫（Jigsaw）、德国低语（German Whispers）、连续线（Renban）、黑白点（Kropki）、X 和（X-Sums）、反马（Anti-Knight）、数比、额外区域、回文、四和、风车、花、三叠和十盒数独。十盒数独采用 10×10 环绕盘面，含十个禁填格和十个 3×3 宫。三叠数独采用 15×15 紧凑错位布局，保留旧布局的存档与回放。组合盘面的重叠格共享数字，窄屏可切换全盘预览与放大滚动。杀手数独中有 27 道无初始数字题目；第 21–30 关为无初始数字、无单格笼的困难挑战，卡片数字下显示“困难”，允许试探回溯。所有题目均验证唯一解。使用 `node scripts/generate-killer-hard.cjs` 按固定种子重新生成后 10 关，`node scripts/generate-killer-hard.cjs --report` 重新评估全部杀手题，`node scripts/verify-killer-hard.cjs` 验证难题与界面。程序评级记录在 `scripts/killer-difficulty.json`，包含笼组合、唯一候选、候选数组、45 法则后的推进程度及固定搜索指标，不代表专业人工评级。可用 `node scripts/generate-sudoku-variants.cjs` 离线补齐变体题库，用 `node scripts/generate-sudoku-extensions.cjs` 生成新增八类变体，用 `node scripts/verify-sudoku-variants.cjs` 验证规则和界面。

象棋页面新增「人机对战」，可选普通、困难、大师，可选择执红先手或执黑后手，界面沿用五子棋的分类栏、难度按钮与红黑开局卡片。皮卡鱼引擎与模型在浏览器本地计算，进入对战时才加载约 68 MB 的离线资源；支持直接打开本地 `index.html` 与 GitHub Pages，无需另装服务。提供整轮悔棋和重开，切到后台或退出时停止计算。引擎来源、模型校验值和许可见 [皮卡鱼来源说明](licenses/pikafish/SOURCE.md)。

五子棋人机对战使用 Rapfi 专用引擎和官方训练的 Mix9SVQ NNUE 自由规则模型，本地 WebAssembly Worker 计算。普通、困难、大师分别使用约 0.2、1、3 秒搜索预算，并设不同搜索深度上限；三档均使用模型。首次进入人机计算时按需加载约 11.3 MB 引擎与模型，在线资源校验后保存至 `dependencies/rapfi/` 或浏览器缓存；双击 `index.html` 使用随项目附带的离线兼容资源。支持原有悔棋、重开和续局，退出或进入后台时停止计算；加载失败可重试。残局仍使用独立 VCT 求解器。来源和许可证见 [Rapfi 来源说明](licenses/rapfi/SOURCE.md)，构建与验证见 `scripts/rapfi/README.md`。

斗兽棋支持简单、普通、困难三档本地人机与同屏双人对战，可选择执红先手或执蓝后手，支持合法落点提示、整轮悔棋、重开确认、键盘操作、离线续局和游戏存档导入导出。棋盘可在右侧切换横竖布局并记住偏好，采用正面动物头像与草地池塘地图，支持移动、跳河和吃子动画，并遵循系统及应用的减少动态效果设置。AI 接入 MIT 开源的 MistyJungle 专用引擎，WASM 与 Worker 随离线包提供，无需联网、首次下载或安装服务；简单、普通、困难每步约思考 0.1、0.7、3 秒。引擎故障时暂停并提供重试，不切换回旧 AI。源码固定、规则适配与构建说明见 `scripts/misty-jungle/README.md`。采用狮虎均可横纵跳河、鼠阻跳、敌方陷阱降级的规则，三次重复局面或连续 100 步无吃子判和。验证：`node scripts/verify-jungle.cjs`；追加 `--unit` 仅运行规则与 AI 测试。

## 使用方式

直接访问在线页面即可使用；下载完整项目后，也可以打开 `index.html` 离线使用。

建议定期导出备份，更换浏览器或设备时通过备份迁移数据。

象棋人机对弈在线使用独立的 WASM 和模型资源，首次需下载约 51 MB，之后优先复用本地依赖。页面完整显示且站点资源请求空闲后，即使不打开游戏也会以低网络优先级补齐缓存，不受点击、输入、滚动、网速或省流量设置限制，也不会启动引擎。后台失败不打扰页面，恢复联网后重试一次；下载期间打开人机对弈会共用请求。已授权运行文件夹时，资源保存在 `dependencies/pikafish/`；未授权或目录不可用时，使用浏览器缓存。目录保存成功后删除对应的浏览器模型副本，避免长期重复占用空间。依赖按内容校验并清理旧版本，可删除后重新下载，不包含在数据备份及运行文件夹迁移中。进入人机设置页会提前准备引擎，空闲引擎可供重新开局复用，退出或进入后台时释放。双击 `index.html` 仍使用原有离线兼容包。

首次设置运行文件夹会在所选目录内创建 `backups/`、`ebooks/` 和 `music/`，并在 `backups/` 下创建 `automatic/` 和 `manual/`。已有目录复用，缺失目录补建。设置中的目录按钮打开“修改运行文件夹”，选择新目录后，需点击“更改文件夹”才会切换；默认不迁移，旧文件保留在原位置。勾选“迁移现有文件”会复制上述三个目录的全部内容和子目录，保留源文件及空目录，不迁移其他文件。迁移展示扫描、冲突检查、复制进度和保存设置；同路径内容相同则跳过，内容不同或类型冲突则停止，不覆盖。新旧目录不能互相包含。迁移取消或失败后仍使用原目录，已完成的副本保留，未完成文件尝试清理，可重试并跳过相同内容；只有全部完成且设置保存成功才切换。音乐收藏、播放位置及阅读记录保持关联。目录授权仅保存在当前设备的 IndexedDB，不包含在可迁移备份中。

本地音乐播放器按需递归读取运行文件夹中的 `music/`。可多选文件或导入整个文件夹，文件夹名称和内部层级保留；导入复制文件，源文件保留。同路径内容相同的文件跳过，内容不同使用 `name (2).ext` 等名称另存，同名歌词与音频同步改名。导入显示进度并支持取消，已完成文件保留，未完成文件清理；导入完成不会自动播放。不支持目录写入的浏览器无法持久导入媒体。

支持常见音频格式，具体能否播放取决于浏览器解码能力。歌词优先读取同目录同名 `.lrc`，其次音频内嵌歌词，最后同名 `.txt`；封面读取内嵌图片或同目录同名、`cover`、`folder` 图片。

播放器提供音乐库导航、歌曲与专辑列表、可切换的正在播放及歌词视图，以及固定在底部的播放栏。文件菜单提供导入文件、导入文件夹和刷新目录；更换整个运行文件夹需前往页面设置，导入期间不能更换。右下角播放设置菜单提供播放模式、倍速和睡眠定时。手机端通过歌曲列表和歌词标签切换内容。

右上角的缩小按钮可将播放器收进右下角功能区，与天气、倒计时等面板共用相同高度。迷你播放器保留歌名、歌手、播放暂停和上下首，点击展开按钮可恢复完整界面。切换其他功能时音乐继续播放；耳机图标会打开上次使用的大／小播放器，刷新后也会记住这个选择。首次使用默认打开完整播放器，刷新后仍不会自动播放音乐。

播放器会独立记住收藏、音量、播放模式及进度，不加入工时备份。授权失效时需恢复运行文件夹授权。历史收藏和进度保留，旧媒体经用户导入后重新匹配。刷新后不会自动播放，睡眠定时也不会恢复。

阅读入口当前暂用占位面板。完整阅读模块继续保留并验证，从固定 `ebooks/` 目录按需读取 EPUB、TXT、PDF，使用与音乐相同的文件及文件夹复制导入规则，导入完成不会自动打开书籍。模块提供封面/列表书架、搜索排序、收藏分组、阅读状态、目录、全文搜索、进度、书签、划线笔记和阅读统计。EPUB/TXT 支持排版、配色、分页/滚动及双页；PDF 保持原版，支持缩放、旋转、缩略图和文字批注。扫描 PDF 不含 OCR；不提供朗读、DRM 解密或 PDF 编辑。支持密码 PDF，密码不保存。

阅读数据独立保存，使用“导出阅读备份／恢复阅读备份”迁移，也可导出 Markdown 笔记；阅读备份不含书籍文件、目录授权及密码，不加入工时备份。历史进度和笔记保留，文件内容指纹用于重新导入后的记录匹配。浏览器存储不可用时会提示导出备份。阅读引擎和字体资源均随项目提供；重新生成引擎运行 `node scripts/prepare-reader.cjs`，验证完整模块运行 `node scripts/verify-reader.cjs`，测试会单独加载模块，产品占位入口保持不变。第三方许可见 `licenses/reader.txt`。

阅读器可最小化到主界面右下角，保留正文、翻页、进度跳转和展开，音乐可以继续播放。未选择书籍时也可进入小窗口，显示空态提示，翻页与进度跳转不可用。小窗与完整版共用阅读位置，紧凑排版不会覆盖完整版设置。模式偏好仅记在当前设备，不加入阅读备份；运行文件夹授权有效时，刷新后可恢复上次阅读；授权失效时需先恢复授权。小窗隐藏、被其他界面遮挡或长时间没有阅读操作时，不累计阅读时长。

备份恢复窗口中的“下载当前备份”将完整备份保存到运行文件夹的 `backups/manual/`；恢复入口通过选择备份文件读取。首次打开时会在后台准备备份，之后只更新修改过的部分；如果修改后立即备份，会先等待最新数据准备完成。备份包含工作记录、日程、设置和游戏存档。

新版仍可恢复旧备份；新导出的分块备份需用当前或更新版本恢复，旧版网页无法读取。浏览器内历史快照不能替代导出到外部的备份。

页面设置中可选择每 1、3 或 7 天自动存档一次；到期后在打开网页时触发，默认每天。自动备份固定写入运行文件夹的 `backups/automatic/`，手动备份（恢复前备份及原始数据救援导出）固定写入 `backups/manual/`。已有 `backups/` 根目录内的文件保留原位，不自动迁移。未设置运行文件夹时需先完成目录初始化；授权失效或写入失败时暂停备份，提示恢复授权并重试，不回退浏览器下载，不记录成功时间或自动备份日期。不支持目录写入的环境无法保存备份文件。设置仅允许更换整个运行文件夹，不提供取消关联或浏览器下载入口。音乐、阅读和游戏的独立导出保持原有行为。文件名保留时间后缀与唯一标识，避免覆盖已有文件。

## 3.3.1 版本说明

作息设置、个人设置及 OA 导入的完整控制器移入独立运行包，和游戏交互辅助代码、完整音乐／阅读文案一起在开场动画结束后加载。控制器分批初始化；提前点击会优先加载并保留最后一个目标，支持取消、失败重试及页面关闭清理。OA 外链和剪贴板仍在原始点击事件中调用。首屏入口文案从完整文案自动生成；自动备份、目录初始化和恢复告警仍随启动运行。
