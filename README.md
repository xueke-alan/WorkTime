# HWorkTime · 工时记录

用于记录工时、安排日程和查看作息统计的个人工具，支持电脑和手机使用。

[在线使用](https://xueke-alan.github.io/WorkTime/)

## 基本功能

- **工时记录**：记录上下班、跨日打卡、请假和计划加班，支持批量填写、时间模板与 OA 考勤导入。
- **日程安排**：管理全天、定时和跨天事项，标记待办、进行中、已完成或已取消，支持月、周、双周和三周视图；周视图提供可拖动、调整时长的时间表，并可只显示工作日。
- **统计分析**：查看工时、加班和月度目标进度，分析上下班时间、加班分布及较上月的变化，通过侧栏联动查看每日详情。
- **自定义作息**：设置工作时间、休息时段和加班要求，也可按日期范围调整。
- **日历信息**：提供年度热力图、下班倒计时、天气、节日、农历和历史事件。
- **备份恢复**：数据保存在当前浏览器，支持备份导出、恢复、历史快照及应急备份。
- **个性设置**：提供多种主题，支持简体中文、繁体中文（台湾／香港）、英语、日语和韩语。
- **休闲游戏**：内置 2048、扫雷、贪吃蛇、数独、推箱子、跳一跳、连连看、花了个花、坦克大战和象棋残局。象棋残局有 110 关，包含 100 道一步杀至三步杀和 10 道《适情雅趣》四至六步长杀，支持离线游玩、提示、悔棋和续玩。部分关卡取自 [Xiangqi Arena](https://github.com/dffge552/xiangqi-pwa-offline)，许可见 [题库许可证](licenses/xiangqi-puzzles.txt)。

数独共 320 关：标准数独四档难度各 20 关，12 类变体各 20 关，包括奇偶、温度计、摩天楼、三明治、杀手、箭头、不规则宫（Jigsaw）、德国低语（German Whispers）、连续线（Renban）、黑白点（Kropki）、X 和（X-Sums）和反马（Anti-Knight）。杀手数独中有 17 道无初始数字题目；所有题目均验证唯一解。可用 `node scripts/generate-sudoku-variants.cjs` 离线补齐变体题库，用 `node scripts/verify-sudoku-variants.cjs` 验证规则和界面。

## 使用方式

直接访问在线页面即可使用；下载完整项目后，也可以打开 `index.html` 离线使用。

建议定期导出备份，更换浏览器或设备时通过备份迁移数据。

播放器提供音乐库导航、歌曲与专辑列表、可切换的正在播放及歌词视图，以及固定在底部的播放栏。右上角文件夹菜单可更换或重新扫描目录；右下角播放设置菜单提供播放模式、倍速和睡眠定时。手机端通过歌曲列表和歌词标签切换内容。

顶部备份按钮单击复制完整备份，按住两秒下载文件。首次打开时会在后台准备备份，之后只更新修改过的部分；如果修改后立即备份，会先等待最新数据准备完成。备份包含工作记录、日程、设置和游戏存档。

新版仍可恢复旧备份；新导出的分块备份需用当前或更新版本恢复，旧版网页无法读取。浏览器内历史快照不能替代导出到外部的备份。

页面设置中可选择每 1、3 或 7 天自动存档一次；到期后在打开网页时触发，默认每天。未指定目录时使用浏览器下载，也可在“存档文件夹”中选择并授权固定目录，仅用于自动存档，不改变手动备份或其他下载的位置。目录设置仅保存在当前浏览器及当前网站来源，不包含在导出备份中；重新打开网页可能需要点击“恢复授权并重试”。目录写入失败时提示并等待恢复，不自动改为下载，也不记录存档成功；可选择“使用浏览器下载”切回原方式。不支持目录选择的环境保留下载功能。设置显示最近一次备份时间，文件名使用 `YYYYMMDD-HHmmss` 时间后缀，目录内备份额外使用唯一标识避免覆盖。
