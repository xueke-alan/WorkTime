# 工作记录

无需安装依赖或构建，双击 `index.html` 即可在浏览器中使用。

右下角“天气”标签按设置中的工作城市显示百度实时天气及接口实际提供的预报。
当前支持东莞、上海、深圳、成都、西安、南京、杭州、北京、武汉、苏州；数据由 GitHub Actions 每小时采集，前端读取公开 JSON，
断网时显示最近缓存。首次发布与增加城市的方法见 [天气说明](docs/WEATHER.md)。

为避免多个页面相互覆盖记录，保存使用浏览器 Web Locks 单写者锁。建议使用新版 Edge 或 Chrome；同一浏览器同时打开时，只有取得写入锁的页面可以保存，其他页面可查看、修改并导出备份。关闭其他页面、备份当前未保存修改后刷新，可以重新取得写入权。浏览器不支持锁时会明确提示无法保存。

## 开发与重构

用户运行无需 Node。维护时使用 Node 22.13 及以上，`npm ci` 安装锁定的开发依赖；`npm test` 运行业务测试，`npm run check` 检查 JS 语法，`npm run lint` 检查维护代码，`npm run check:format` 检查格式。`npm run test:browser` 运行 Edge 无界面回归，`npm run test:styles` 比较 66 组整页、88 组资讯、88 组统计及 154 组日历及352组编辑器/弹窗状态的计算样式和位置。样式基线来自 Windows Edge，依赖本机字体；跨平台结果需先核对环境，不能直接覆盖基线。实施阶段和未完成事项见 `docs/REFACTOR_PROGRESS.md`，模块契约见 `docs/ARCHITECTURE.md`。

## 文件结构

性能方法、基线及结果见 `docs/PERFORMANCE_CONTRACT.md`、`docs/PERFORMANCE_COMPARISON.md`；`npm run benchmark -- --samples 20 --output docs/performance-new.json` 可独立复测，`npm run trace -- docs/performance-trace-new.json.gz` 可采集诊断。不要在每个小改动后重复全量测量，按批次在最后集中验证。原生浏览器缩放可使用 `node scripts/review-native-zoom.cjs <唯一输出标签>`，使用临时配置并保留证据，不修改日常浏览器设置。完整交付核对和未解决事项见 `docs/DELIVERY_AUDIT.md`。

- `index.html`：页面、弹窗与内嵌 SVG 图标。
- `assets/css/tokens.css`：主题色、UI尺度、控件尺寸、字体家族和动画时序的根级变量。
- `assets/css/base.css`：全局重置、字体、共享表面、表单默认值与通用工具类。
- `assets/css/layout.css`：工作区、整体页面和页脚的响应式布局。
- `assets/css/editor.css`：单日/批量编辑器、请假浮层、模板列表和共享次日开关。
- `assets/css/dialogs.css`：弹窗容器与模板、设置、导入、恢复等特有结构。
- `assets/css/date-info.css`：资讯页签、历史、节日、黄历及倒计时样式，含组件断点与隐藏/焦点契约。
- `assets/css/summary.css`：统计侧栏、汇总卡片、目标区、数字与单位，以及组件响应式规则。
- `assets/css/calendar.css`：月历、年历、工具栏和图例；按日历容器宽度排版，短窗口月历可内部滚动，见 `docs/CSS_CONTRACT.md`。
- `assets/css/controls.css`：时间、数值输入框与同类按钮的公共视觉样式。
- `assets/js/domain/`：日期值、状态、日历、记录计算、统计、OA 解析回放和备份校验。
- `assets/data/calendars.js`：2020–2026 调休安排及官方来源、覆盖范围和核查日期。
- `assets/js/domain/migrations.js`：旧排班标记迁移，保留用户自定义设置；types.js 提供 JSDoc 数据契约。
- `assets/js/core.js`：保持原有 `WorkTime` 公开接口的兼容入口。
- `assets/js/ui/`：日记录展示、统计、日历、编辑器与通知视图，通过 getter 获取当前状态。
- `assets/js/controllers/`：模板、设置、备份、导入、单日编辑、导航/批量和通用弹窗的事件控制器。
- `assets/js/services/`：启动错误边界、集中应用/导航状态、注入时钟、剪贴板与下载适配器。
- `services/derived.js`：按内存数据版本共享统计结果，保留未保存更改和临时预览的正确性；`services/import-index.js`缓存来源日期查找，原文日期与已接受记录分开。
- `assets/js/app.js`：初始化与依赖连接入口；控制器构造完成后统一注册事件。
- `assets/css/motion.css`：动画行为和关键帧；时长、缓动由tokens.css定义，不使用悬停浮起、悬停阴影增强或按下缩小效果。
- `assets/js/motion.js`：首次入场和明确交互的动画触发；普通保存、输入及倒计时刷新不重播，遵循系统减少动画偏好。
- `assets/js/background.js`：背景粒子动画，遵循系统减少动画偏好。
- 倒计时复用内容节点，仅更新变化的文字；切到其他页签或隐藏页面后停止计时，返回时立即校时。背景粒子随页面可见性与运行中的减少动画偏好暂停/恢复，退出时统一清理。
- `assets/js/ui-alignment.js`：保留日历数字与特殊文字的字形校正；普通按钮按实际字号分类使用公共 CSS 行高和补偿，不按内容计算偏移。`tests/button-ink.browser.cjs`检查24宽度×4 DPR×3类按钮，共288组的实际字形中心和共同基线，并比较同一字号下文字补偿前后的图标与点击区域。
- `licenses/material-symbols.txt`：Material Symbols 图标来源与 Apache 2.0 许可证。

普通脚本通过 `defer` 按 index.html 中的依赖顺序加载：domain 模块先于 core，再加载其余功能模块和 app。不要改为异步加载或 ES Modules，以保留双击运行方式。SVG 图标保留在页面中，避免本地文件的跨文件引用限制。

## 数据与迁移

记录保存在当前浏览器的 localStorage 中，存储键为 `worktime-local-v1`。请定期下载 JSON 备份；备份格式与拆分前兼容。

恢复时会校验记录、设置、模板与导入历史，错误提示包含具体字段路径。旧备份缺失的可选设置仍兼容；已填写的非法时间或不合法记录不会静默改写后恢复。初始化失败时页面提示错误并禁用操作，请检查项目文件是否完整后重新打开；此时不会用默认数据覆盖原有存储。

移动或分发时请保留整个目录及相对路径，不能只复制 HTML。移动位置、切换浏览器或清理浏览器数据前先备份，之后按需恢复；本地文件的存储行为取决于浏览器。恢复备份会替换当前浏览器中的记录和设置。

## 月度加班条件

计算设置中配置最低要求及非工作日加班 1、2、3、4 天及以上的要求，单位为小时/折算出勤日。最低要求沿用旧月均目标，其他档位首次为空；适用档位为空时需先配置。非工作日可标记计划加班，有完整有效工时的日期计为实际加班，与计划同日去重。调休补班按工作日处理。非工作日工时只影响档位，仍单独统计，不抵扣工作日目标。

计划与条件随 JSON 备份迁移。旧备份恢复后仅保留最低要求，其他档位为空。运行 `node tests/monthly-requirements.test.cjs` 可验证规则与备份兼容。

历史月份或没有剩余可分配工作日时，目标区保留差额、已达标或超出目标；每日分配显示“-”。缺少工作日记录时显示缺数据说明，正差额标为“记录内差额”，补齐后才显示“未达标差额”。不会因为月份结束把差额改为零。

应用中的“今天”和当前年份使用中国标准时间，与下班倒计时一致。跨午夜或从休眠恢复后会刷新统计、日历与通知，保留当前选中的日期和正在填写的输入；点击“今天”再跳转到当前日期。

## 本地日期资讯

右栏底部提供通知、历史上的今天、节气及节日、农历黄历图标页签；内容跟随选中日期。所有资料保存在项目内，离线可用。农历和黄历支持 1900–2100 年，黄历为传统民俗参考。资料来源与扩展方式见 `assets/data/README.md`。运行 `node tests/date-info.test.cjs` 验证资料及日期规则。

## 下班倒计时

时钟图标页签始终计算中国标准时间的当天，不跟随日历选中日期。优先使用名称为“常规下班”的时间模板，未配置该模板时使用计算设置中的标准下班时间；部分请假不改变常规下班时刻。休息日且无计划加班或完整工时记录时不倒计时，全天请假也不倒计时。到点显示“已到下班时间”，每秒更新；切回页面时恢复实时计算。支持模板的次日下班设置。运行 `node tests/work-countdown.test.cjs` 验证规则。

## 发薪日

实际发薪日期的日历卡片在日期数字右侧显示红色圆形人民币图标，不提供独立页签。图标提示显示实际日期；提前时说明原定日期及提前天数。每月15日发薪；遇节假日或周末，提前至最近的工作日，调休补班日按工作日处理。使用内置2020–2026年调休日历，覆盖外年份按周一至周五推算；个人请假或计划加班不改变发薪日期。运行 `node tests/payday.test.cjs` 可验证规则。

## 年视图

点击日历左上角的年月，在月视图与全年热力图间切换。年视图左右箭头切换年份；点击日期返回对应月份并选中当天。加班颜色按所选年份的 0 小时到最长加班时长向上取整后的整数小时连续渐变，其他时长按比例插值；无完整记录使用零值颜色；欠工时使用红色连续渐变，负数下限按最少记录向下取整到整数小时，年视图只展示加班颜色，点击日期查看详情。每个月上方显示月份标题，切换年／月视图时使用渐显动画，并遵循系统减少动画设置。侧栏统计和目标仍对应原来选中的月份。

运行 `node tests/year-view.test.cjs` 验证全年日期和热力图规则。已安装 Playwright 与 Edge 的环境可运行 `node tests/year-view.browser.cjs` 验证交互和响应式布局。
