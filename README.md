# HWorkTime · 工时记录

用于记录工时、安排日程和查看作息统计的个人工具，支持电脑和手机使用。

[在线使用](https://xueke-alan.github.io/WorkTime/)

## 基本功能

- **单词学习**：右栏全栏学习页面，内部分为复习、选词、统计、设置四页，点击复习直接进入背词，完成后仅显示连续天数和今日学习总结，保留底部功能导航；支持切换功能后恢复当前练习和未完成输入，支持日常用语、六级、考研、托福、雅思五类词书。内置 11,124 个去重词条／读音义项（含 100 条原创场景短语）；考试分组来自 ECDICT 标签，并非官方完整考纲。提供记忆卡、中文提示拼写、听音拼写、收藏、搜索、近 30 天学习量、活跃日历及最近评分分布；FSRS 按练习类型独立调度，默认每日 20 个新词、目标保持率 90%。学习记录纳入全站备份，恢复不含本模块的旧备份时保留现有进度。支持 Piper 与 Supertonic 3，通过 WASM Worker 本地生成发音，每次打开背单词时自动检查模型，缺失或不完整时从 GitHub Release 下载并校验，保存到运行文件夹后可断网使用；首次即断网时，可在学习设置中导入独立 `.wtmodels` 模型包。美音固定使用 Supertonic 3 F1，英音固定使用 Piper en_GB-jenny_dioco-medium；无模型选择项。Piper 输出 22.05 kHz，正常语速、noise_scale 0.5、noise_w 0.333，分别使用模型指定的美式与英式 RP 音素规则；Supertonic 输出 44.1 kHz，16 步、语速 1.05，使用通用英语音色。学习设置支持口音切换和自动缓存管理。模型安装完成后，页面启动 2 秒后即可后台生成；未安装的模型由打开背单词时自动检查或设置中的下载按钮获取，后台任务不主动下载模型；鼠标移动、普通点击和滚动不打断，编辑或拖拽结束 2 秒后继续，游戏打开和前台发音期间不启动下一词，已启动的合成仍完成并保存。先补齐当天复习词、新词及已学词的英美双音，再补齐全词库当前所选口音，最后补齐另一口音，前台优先，达到容量上限后暂停。模型及配置分别存入运行文件夹 `english/resources-piper/` 和 `english/resources-supertonic-3/`，音频存入 `english/audio/`，缓存身份包含模型版本、音素转换版本、说话人和合成参数；缓存不进入学习备份。游戏模型统一存入 `game/`；旧 `dependencies` 中的已识别资源会校验迁移，冲突或未知文件保留。专项检查：`node scripts/verify-vocabulary-cache.cjs`。重建资源：`npm run prepare:vocabulary`（首次需要联网）；检查：`npm run check:vocabulary`，追加 `--unit` 仅检查调度、存档与资源校验。第三方许可见 [单词学习许可](licenses/vocabulary.txt)。

- **打字学习**：独立学习入口，沿用网站主题与六语言界面。提供 600 关英文 QWERTY 课程，逐关解锁、键盘和指法提示、最高五星、1/3/5 分钟测速、自定义文章、薄弱项训练、限时消词与本地竞速。统计包含速度、准确率、每日时长、连续学习、徽章和错键热力图；最近 200 次练习可回放。进度、草稿、文章和记录自动本地保存并纳入全站备份，恢复不含学习模块的旧备份时保留当前学习数据。内容为项目原创，见 [课程许可](licenses/typing-curriculum.txt)。重建：`node scripts/generate-typing.cjs`；验证：`node scripts/verify-typing.cjs`（追加 `--unit` 只检查课程与规则）。桌面界面针对 1920×1080 与 2560×1440 全屏优化，课程、自由练习、挑战、统计、训练、结果及回放均可单屏展示；文章和历史记录使用分页，长文章在文本区域内滚动。布局验证：`node scripts/verify-typing-layout.cjs`。

- **三国华容道**：300关，入门、简单、普通、进阶、困难、大师六档各分两组，共12组、每组25关；全部至少需要两步出关，优先使用206个具名布局（45个经典名局、161个发芽网具名题），支持具名筛选；局名最多5字，原题名与来源保留在题库资料中。普通、进阶、困难、大师四档全部采用具名布局；入门和简单保留必要的循序渐进题目。采用同一棋子连续移动（含拐弯）算一步的传统计步；支持鼠标拖动、手机滑动、键盘操作、整步撤销、重玩、离线续局和游戏存档导入导出。不提供提示、解法演示或理论最少步数。经典布局来源与MIT许可见 [题库许可](licenses/klotski-puzzles.txt)；运行 `node scripts/klotski/build.cjs` 可重建题库，运行 `node scripts/verify-klotski.cjs` 校验分级、解法证书、规则、存档和界面。

- **飞行棋**：四席可分别选择真人或电脑，默认一人对三台电脑，支持简单、普通、困难、同屏多人、暂停、离线续局和游戏存档导入导出。棋盘采用连续直角航道、三角转角、小型基地和中央四色终点。六点起飞与连掷、同色跳格、跨盘飞跃、撞机及终点反弹均由共享规则实现。三个难度使用随包附带的真实自训练模型，在本地 Worker 推理；无需接口密钥。普通、困难对三名固定策略对手各 2,000 局胜率分别为 33.65%、40.25%，模型与档位均通过评测。训练命令与规则见 [飞行棋指南](scripts/aeroplane/README.md)，数据及置信区间见 [评测报告](scripts/aeroplane/EVALUATION.md)。



- **熄灯谜题**：沿用数字华容道的布局，点击图案翻转自身与上下左右相邻图案，让所有图案归于沉静。共 100 道原创预设谜题，4×4 至 7×7 各 25 关，分别搭配深海光珠、星夜、晶洞和能量光环美术；全部采用高难度题目，每章按精确最少步数排序，全部关卡开放，支持撤销、重开、最佳成绩、离线续玩及游戏存档导入导出。
- **工时记录**：记录上下班、跨日打卡、请假和计划加班，支持批量填写、时间模板与 OA 考勤导入。
- **日程安排**：管理全天、定时和跨天事项，标记待办、进行中、已完成或已取消，支持月、周、双周和三周视图；周视图提供可拖动、调整时长的时间表，并可只显示工作日。
- **统计分析**：查看工时、加班和月度目标进度，分析上下班时间、加班分布及较上月的变化，通过侧栏联动查看每日详情。
- **自定义作息**：设置工作时间、休息时段和加班要求，也可按日期范围调整。
- **日历信息**：提供年度热力图、下班倒计时、天气、节日、农历和历史事件。
- **备份恢复**：数据保存在当前浏览器，支持备份导出、恢复、历史快照及自动备份。
- **个性设置**：提供多种主题，支持简体中文、繁体中文（台湾／香港）、英语、日语和韩语。
- **本地音乐**：右下角音乐按钮打开播放器，像游戏模式一样从中间栏展开，导入本地音乐后可播放、搜索、收藏，支持循环、随机、倍速、睡眠定时和本地歌词；收起后恢复原视图并继续播放。
- **休闲游戏**：内置 2048、扫雷、贪吃蛇、数独、推箱子、跳一跳、连连看、羊了个羊、坦克大战、象棋残局和五子棋残局。五子棋残局沿用象棋的选关与对弈布局，提供 100 道原创 VCT 连续威胁残局，按初级 40 题、中级 30 题、高级 30 题分类；旧版一步、两步、三步基础题已全部移出菜单。VCT 已验证路线为黑方 4–6 步，结合活三衔接次数与搜索复杂度排序，排除平移、旋转、镜像重复及相同黑方棋形，采用 15×15 无禁手规则，支持自动应手、整轮悔棋、重开、键盘操作、离线续局和游戏存档导入导出。象棋残局有 200 关，包含一步杀 20 题、两步杀 30 题、三步杀 30 题，以及 120 道具名《适情雅趣》经典长杀；基础题连续编号 01–80，经典题按初级（4–5步）、中级（6–8步）、高级（9步以上）分类，支持离线游玩、悔棋和续玩。部分关卡取自 [Xiangqi Arena](https://github.com/dffge552/xiangqi-pwa-offline)，许可见 [题库许可证](licenses/xiangqi-puzzles.txt)。
- **推箱子进阶题库**：共 140 关，采用入门、进阶、熟练、专家、高阶专家、极难、大师七档，各 20 题，分别搭配清新森林、沙漠遗迹、琉璃花房、冰川遗迹、太空基地、黄铜工坊、云端天宫七套浅色美术。原有 100 题的稳定 ID、地图和解法全部保留，展示编号按新分档重排，旧进度按 ID 恢复。来源为 David W. Skinner 的 Microban / Sasquatch，许可见 [题库说明](licenses/sasquatch.txt)。全部解法已回放验证，新题解法不宣称最优；支持离线游玩、续玩和存档导入导出。
  题库重建：`node scripts/import-sokoban.cjs`；一致性检查：追加 `--check`。固定选题、旧题兼容指纹和新顺序在 `scripts/sokoban-selection.json`。统一难度指标为推箱次数 + 3×箱子切换次数 + 12×移出目标次数 + 5×箱子数，按分值与稳定 ID 排序后每 20 题分档。名称与分数区间参考 [Cosmos 作者的七档说明](https://aymericdupeloux.wixsite.com/sokoban/post/welcome)，题目归档为本地估计，不是原作者对这些题目的评级，也未使用其需要另行许可的题库。诊断求解：`node scripts/import-sokoban.cjs --solve sasquatch-5 3`（有预算限制，不改题库、不宣称最优）；求解使用反向推箱距离与箱子／目标最小代价匹配。地图限制在 20×20 格以内，排除原文注明的 SokHard 衍生题。

数独共 640 关：标准数独四档难度各 20 关，风车、花、三叠和十盒数独各 20 关，杀手及其他 15 类单盘 9×9 变体各 30 关。每类 30 关的变体在第 21–30 关显示“困难”。已有困难题按程序评级移到后 10 关，超出 10 关的旧题留在兼容题库，原有存档和回放数据继续保留。十盒数独采用 10×10 环绕盘面，含十个禁填格和十个 3×3 宫。三叠数独采用 15×15 紧凑错位布局，保留旧布局的存档与回放。组合盘面的重叠格共享数字，窄屏可切换全盘预览与放大滚动。杀手数独中有 27 道无初始数字题目；第 21–30 关为无初始数字、无单格笼的困难挑战，卡片数字下显示“困难”，允许试探回溯。所有题目均验证唯一解。使用 `node scripts/generate-killer-hard.cjs` 按固定种子重新生成后 10 关，`node scripts/generate-killer-hard.cjs --report` 重新评估全部杀手题，`node scripts/verify-killer-hard.cjs` 验证难题与界面。程序评级记录在 `scripts/killer-difficulty.json`，包含笼组合、唯一候选、候选数组、45 法则后的推进程度及固定搜索指标，不代表专业人工评级。其他 15 类的程序评级记录在 `scripts/sudoku-variant-difficulty.json`；使用 `node scripts/generate-sudoku-hard.cjs` 重建，追加 `--check` 校验可重复性。可用 `node scripts/generate-sudoku-variants.cjs` 离线补齐变体题库，用 `node scripts/generate-sudoku-extensions.cjs` 生成新增八类变体，用 `node scripts/verify-sudoku-variants.cjs` 验证规则和界面。

## 使用方式

游戏菜单新增 UNO 单机对战：总人数可选 2～8 人，1 名真人与其余 AI 对战，默认 4 人、普通难度。中央通过不透明的同色方向箭头与悬浮指针表达方向、颜色和当前玩家，方向切换以短暂加速反转衔接箭头变化；真人手牌与中央圆桌共用中轴，扩大牌桌宽度并将右栏右移；摸牌堆完整显示于左下，右上角仅保留较大的重开和设置图标按钮，移除右栏，规则保留于设置页，手机端自适应至下方。AI 每步约等待 0.74 秒后行动，出牌约 160ms 后整理手牌，增减都有平滑重排，回合高亮使用颜色渐变。顶部恢复游戏标题，固定牌桌、手牌与提示区域高度；底部不再重复显示玩家说明，手牌悬停时立起抽出但保持原层叠顺序，可出牌保留白色卡边，悬停时白色间隙和同色边缘整体渐显，保留抬牌前的底部命中区域以避免抽搐，变色牌悬停或键盘聚焦后出现可直接选择的四种趋向圆形的手绘颜料色块，2×2 排列并与牌面等宽，按钮保留 44px 高度，悬停可预览牌面与文字颜色，色块出现和消失都有过渡，跨越间隙仍保持抽牌状态；仅点击色块出牌，变色牌飞出时就开始渐变为所选颜色，落牌时延续飞行中的配色，只在真人实际回合将无法出的牌整体轻度降低饱和度和亮度，保留原色识别度，交出回合后保留正常颜色约 800ms，再整体轻度淡化，摸入和恢复可出状态都有颜色渐变。AI 使用随存档保存的随机卡通头像和名称，弧形手牌位于头像上方，7～8 人局按牌桌实际宽高自适应放大卡牌、头像和文字，宽屏卡牌可增至 64～70px，紧凑桌面保持 44～50px，手机至少 24px；头像、名称和牌数留在完整牌弧下方，仅当前行动 AI 的牌背高亮。开局等窗口展开后按接收顺序逐张发牌，尺寸通知不会取消发牌或摸牌动画，发完后以有效布局坐标执行动画排序，再从牌堆顶部逐张翻出起始牌；功能牌留在弃牌堆且不触发效果，直到出现第一张数字牌才开放回合；AI 本次引入旧版网页无法读取的分块备份格式，按备份格式不兼容变更发布主版本 2.0.0；已发布的历史版本保持原编号。

超级井字棋支持同屏双人和简单、正常、困难三档人机，使用 uttt.ai 已训练 NMCTS2 模型在本地推理。落子位置指定对手下一步区域；大棋盘三区连线立即获胜，无合法落子时以占领区域数决胜。可勾选「连锁清盘」：新占领区域后清空其他所有未被占领的小棋盘，包括平局棋盘。支持悔棋、重开、六语言、键盘、离线续局和游戏存档导入导出。在线模型资源参考象棋机制预下载并保存至 game/utttai/ 或浏览器缓存；直接打开 index.html 使用离线兼容包。引擎来源、构建和 160 局档位评测见 scripts/utttai/README.md。

## 加载与离线维护

在线应用安装缓存时会完整准备启动脚本、六种语言、关键样式及其图片依赖；更新按资源内容生成独立缓存，安装失败时保留旧缓存。带内容哈希的静态资源优先复用缓存，页面入口网络失败或等待超过三秒时回退已缓存入口。游戏大型引擎资源继续由各自的资源服务管理，未使用过的游戏不承诺完整离线可用。

统计样式在进入统计页时加载，恢复上次统计视图时先等待样式就绪；游戏会话样式在创建游戏前加载，菜单和共用工作区样式保留在首屏。日程卡片更新位于 `assets/js/ui/agenda-card-renderer.js`，周视图卡片动画位于 `assets/js/ui/agenda-chip-motion.js`，主控制器保留视图和持久化协调。

首屏完成后，`assets/js/services/game-prefetch.js` 会闲时预加载所有游戏的规则、关卡、界面脚本与样式，以及音乐、阅读、打字应用界面和打字课程，再逐项缓存四种棋类引擎资源。界面资源只预加载，不执行游戏工厂、不打开卡片、不播放媒体。HTTP 与直接打开文件均支持界面预加载；大型在线引擎仍复用各自的资源缓存。

资源预加载和单词发音生成复用同一个闲时判断：启动 2 秒后开始，输入、输入法组合、拖拽、AI 模型加载与推理、前台发音期间暂停，结束 2 秒后继续；普通鼠标移动、点击、滚动、普通小游戏，以及全尺寸音乐和电子书窗口均不打断。AI 模型是否忙碌由引擎任务报告，不根据窗口尺寸或游戏是否打开判断。每次只安排一项后台资源，前台可共享请求并提升对应任务优先级。后台失败静默处理，恢复联网后最多重试一次，离开页面后停止调度新任务。

修改源模块后运行 `npm run prepare:assets` 同步运行包与 `offline-shell.js`；发布构建会根据打包后的真实 URL 重建离线清单。可使用 `node scripts/verify-game-prefetch.cjs`、`node scripts/verify-offline-shell.cjs` 和 `node scripts/verify-deferred-styles.cjs` 验证调度、HTTP 断网启动及延迟样式；后两项追加 `_site` 验证发布产物。首屏 CSS 上限收紧为 325 KB。

## 单词学习的英美口音

在「单词学习 → 学习设置 → 口音」选择美音或英音；音标、朗读和全词库空闲音频生成的优先口音同步切换，已有缓存、学习进度和未完成输入保留。美音固定 Supertonic 3 F1，英音固定 Piper Jenny Dioco；前台朗读和后台生成同步切换。两种口音分别缓存，共享总容量上限。升级时清理已停用音色的已识别模型和音频缓存，保留当前两种音色缓存及学习进度。

全部 11,124 个词条／短语均随包提供英美音标与合成音素。音标优先保留人工多音词校正，再采用有明确地区标记的 Wiktionary 词典数据，缺失或无法可靠转换的音标由 eSpeak NG 离线生成，界面标注「自动生成」。当前精简快照来自 Simple English Wiktionary，经 Kaikki / Wiktextract 提取；来源、日期和 SHA-256 位于 `scripts/vocabulary/dictionary.json`，覆盖统计及转换待校正列表位于 `scripts/vocabulary/pronunciation-report.json`。词典衍生数据采用 CC-BY-SA-4.0，署名和来源链接见 `licenses/vocabulary.txt`。

普通重建使用已保存的精简快照：`npm run prepare:vocabulary`，随后运行 `npm run prepare:assets`。只有主动刷新词典时才运行 `node scripts/vocabulary/import-dictionary.cjs`；追加 `--full` 可从较大的 English Wiktionary 快照刷新，使用可续传分块下载。刷新后重新运行上述两项构建。词典原始大文件不会随应用分发，使用时无需联网。

### 英语语音资源

「音标自动生成，待核验」只说明音标来源，不代表合成声音已经核验；没有该提示的词条也可能出现模型误读。

重建轻量语音运行库与模型清单：`npm run prepare:speech`（不下载模型）；重建词库及配套资源：`npm run prepare:vocabulary`。模型来自固定版本的原始仓库，文件规格与 SHA-256 固定在 `scripts/vocabulary/speech-files.json` 和 `scripts/vocabulary/supertonic-files.json`。生成独立离线模型包：`npm run package:speech`，默认输出 `.cache/speech-packages/worktime-speech-models-v1.wtmodels`，可追加 `-- --engine=piper` 或 `-- --engine=supertonic` 生成单引擎包，包不进入 Git。学习设置支持下载、取消与离线包导入，安装前验证整个包。分发验证：`node scripts/verify-vocabulary-models.cjs`；真实断网合成验证：`npm run check:speech -- --http --with-folder --package=.cache/speech-packages/worktime-speech-models-v1.wtmodels`。运行文件夹的 `english` 和 `game` 与 backups、ebooks、music 并列，源码目录不变。

音频缓存容量支持 5 GiB、15 GiB、20 GiB 和不限制；旧容量设置向上迁移到可用档位。新音频按哈希前两位分入 256 个目录，读取时直接查找目标文件，兼容原有平铺目录和旧 `dependencies/vocabulary` 路径。IndexedDB 仅保存文件元数据及容量汇总；首次统计和「校验缓存」分批在闲时执行，统计未完成时暂停新增磁盘音频，已有音频仍可播放。手动修改缓存文件后可点击「校验缓存」重新统计。清空缓存保留模型文件。大规模验证：`node scripts/verify-vocabulary-large-cache.cjs`，使用 20 万条真实持久化元数据模拟 20 GiB 音频容量，不写入 20 GiB 音频内容。

单词复习快捷键：空格与点击空白区域一样显示答案；显示答案后，← 认识、↓ 模糊、→ 忘记。↑ 可撤回刚完成的一词评分，回到答案页修正，原评分按钮加深；不能连续向前回退，修正后也不能再次撤回同一词。撤回会恢复该词评分前的记忆调度并移除对应日志，重新评分只保留修正结果。快捷键不在输入框、设置页或其他功能中触发。

模型统一从 https://github.com/xueke-alan/WorkTime/releases/tag/speech-models-v1 分发。原始模型及浏览器分片均为 Release Assets，不进入 Git 历史；分片还原后仍按原始 SHA-256 校验。设置中的发音模型与缓存各有一组操作，下载进度显示在底部状态栏。
